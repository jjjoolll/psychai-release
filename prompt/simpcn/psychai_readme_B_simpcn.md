# PsychAI 使用说明书（Option B · 提示词版）
# 作者：伪63 | 版本：v1.1 | 2026-05-15

---

## 这是什么

PsychAI 是一个系统提示词，粘贴进**任意聊天型 AI**（如 Claude、ChatGPT、豆包等）之后，能把它变成一个专注于个人心理分析的对话助手。它基于十多个临床心理学框架——包括 Big Five 人格、依恋理论、防御机制、图式疗法等——通过你主动提供的材料，帮你建立一份属于自己的心理档案。

它不是心理治疗软件，没有医疗功能。它更像一个有完整心理学知识储备的对话伙伴，能帮你看到自己看不见的地方。

---

## Option A 还是 Option B？

PsychAI 有两个版本，你正在看的是 **Option B（提示词版）**。

| | Option B（本文） | Option A |
|--|--|--|
| 使用方式 | 粘贴提示词到任意 AI | Claude Code 本地 Skill |
| 安装门槛 | 零安装，即开即用 | 需要安装环境（约 30 分钟） |
| 特色 | 任何 AI 均可，免费版足够 | 自动读取本地文件，分析结果持久保存 |
| 适合谁 | 想快速体验的用户 | 想要完整自动化体验的用户 |

如果你想要更完整的体验，可以参考 [**Option A 说明书**](../../skill/simpcn/psychai_readme_A_simpcn.md)。

如果你已经是 Option A 用户，需要在没有 Claude Code 的设备上临时使用 PsychAI，可以用 Option B 过渡：把本地 `.profile.md` 的内容复制出来，在新对话开头以快照格式（`【PsychAI档案快照】`）传入，分析会直接从你的现有档案继续，不需要重新走问卷。

## 开始之前需要准备什么

**你需要：**
- 任意一个聊天型 AI 账号，例如：
  - **Claude**（claude.ai）— 免费版可用，Pro 版上下文更长
  - **ChatGPT**（chat.openai.com）— 免费版可用，GPT-4o 效果更好
  - **豆包**（doubao.com）、**Kimi**、**DeepSeek** 等国内 AI 均可
- 大约 5-10 分钟完成初次问卷

**你不需要：**
- 任何技术知识
- 心理学背景
- 提前准备材料（边聊边给也可以）

## 怎么用

**第一步：获取提示词文件**

从文件包里打开 `psychai_prompt_v1_simpcn.md`，把"以下内容为系统提示词正文，请从此处复制"下面的全部内容复制下来。或者直接把文件上传到 AI 对话里，不用复制粘贴。

**第二步：加载提示词**

有三种方式，选一种：

- **方式 A（推荐，Claude）**：在 claude.ai 创建一个新 Project，进入 Project 设置，把提示词粘贴进「System prompt」字段，然后在这个 Project 里开始对话。同一 Project 里的对话都会自动加载，不需要每次重复。

- **方式 B（上传文件）**：直接把 `psychai_prompt_v1_simpcn.md` 上传到对话里，AI 会自动读取文件内容。Claude、ChatGPT 等均支持。

- **方式 C（通用）**：在任意 AI 平台开一个新对话，把提示词正文作为第一条消息发送，然后继续聊。每次新对话需要重新发送。

**第三步：跟着它的引导走**

它会先自我介绍，然后引导你回答几个问题。问题没有对错，写多写少都行，越具体它分析得越准。

你也可以跳过问卷，直接把日记、聊天记录或者其他材料扔给它开始分析。

## 什么材料最有用

它能处理各种文字材料，以下这些效果最好：

| 材料类型       | 说明                                       |
|--------------|------------------------------------------|
| **日记/随笔** | 任何你写过的，关于自己、情绪、事件的文字             |
| **聊天记录** | 和朋友、家人、伴侣的对话片段（复制粘贴即可）           |
| **录音转写** | 对自己说话的录音、和他人对话的录音，转成文字后粘贴进来 |
| **随手写的东西** | 不需要是正式的，碎片也行                       |
| **直接对话** | 不提供材料、直接跟它聊，也能做分析                 |

材料字数越多，通常分析越准确，因为能看到的行为模式更完整。

## 跨对话保存进度（快照功能）

大多数 AI 每次新开对话都不记得上次聊了什么。PsychAI 用"快照"解决这个问题：

**生成快照**：完成第一次分析后，它会自动在输出末尾附上一段 `【PsychAI档案快照】`，格式是结构化的档案摘要。

**使用快照**：下次开新对话时，把这段快照粘贴到对话最开头，它会直接从你的当前档案状态继续，不需要重新走一遍问卷流程。

**更新快照**：每次提供新材料、档案有实质更新后，它会自动附上新的快照。用新的覆盖旧的保存就行。

建议：把最新的快照存在一个固定的地方（备忘录、文档都行），每次用之前复制一下。

## 它不能做什么

- **不是心理治疗**：它的分析基于你提供的文字，不能替代面对面的专业评估
- **没有医疗功能**：不能诊断任何心理疾病，不能开具任何建议或治疗方案
- **不存储你的数据**：所有内容只存在于你和 AI 的对话里，关掉就没了（这也是需要快照的原因）
- **分析有局限**：它只能看到你愿意说的部分，隐瞒的部分它不会知道

如果你的情况已经比较严重，影响到了正常生活，请寻求专业的心理健康帮助。

## 常见问题

**Q：用哪个 AI 比较好？**
哪个你用得顺手就用哪个。Claude、ChatGPT 的上下文窗口较长，处理大量材料时更稳定；豆包、Kimi 等国内 AI 无需梯子，更容易上手。免费版通常够用，有大量材料需要分析时付费版体验更好。

**Q：我的隐私会被泄露吗？**
你的对话内容由你所使用的 AI 平台处理，PsychAI 本身不收集任何数据。各平台的隐私政策不同，建议查阅你所用平台的官方说明。如果对隐私有顾虑，可以在提供材料时对人名等敏感信息做模糊处理。

**Q：它分析的结论准吗？**
它基于你提供的材料做推断，材料越真实完整，分析越接近实际情况。如果它的结论跟你的判断不符，可以直接告诉它，它会根据你的纠正更新分析。你对自己的了解永远优先于它的推断。

**Q：可以一次分析多个人吗？**
可以，你可以提供关于其他人的材料（比如和某人的聊天记录），让它帮你分析对方，或者分析你们之间的关系动态。

**Q：它支持中文以外的语言吗？**
支持。如果你用英文或繁体中文和它交流，它也能理解并回应。本说明书另有繁体中文版和英文版，见同一文件包内。

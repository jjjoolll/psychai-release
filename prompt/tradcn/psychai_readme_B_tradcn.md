# PsychAI 使用說明書（Option B · 提示詞版）
# 作者：偽63 | 版本：v1.1 | 2026-05-15

---

## 這是什麼

PsychAI 是一個系統提示詞，載入**任意聊天型 AI**（如 Claude、ChatGPT、豆包等）之後，能把它變成一個專注於個人心理分析的對話助手。它基於十多個臨床心理學框架——包括 Big Five 人格、依附理論、防禦機制、圖式療法等——透過你主動提供的材料，幫你建立一份屬於自己的心理檔案。

它不是心理治療軟體，沒有醫療功能。它更像一個有完整心理學知識儲備的對話夥伴，能幫你看到自己看不見的地方。

---

## Option A 還是 Option B？

PsychAI 有兩個版本，你正在看的是 **Option B（提示詞版）**。

| | Option B（本文） | Option A |
|--|--|--|
| 使用方式 | 貼提示詞到任意 AI | Claude Code 本地 Skill |
| 安裝門檻 | 零安裝，即開即用 | 需要安裝環境（約 30 分鐘） |
| 特色 | 任何 AI 均可，免費版足夠 | 自動讀取本地檔案，分析結果持久保存 |
| 適合誰 | 想快速體驗的使用者 | 想要完整自動化體驗的使用者 |

如果你想要更完整的體驗，可以參考 [**Option A 說明書**](../../skill/tradcn/psychai_readme_A_tradcn.md)。

如果你已經是 Option A 使用者，需要在沒有 Claude Code 的裝置上臨時使用 PsychAI，可以用 Option B 過渡：把本機 `.profile.md` 的內容複製出來，在新對話開頭以快照格式（`【PsychAI檔案快照】`）傳入，分析會直接從你的現有檔案繼續，不需要重新走一遍問卷。

## 開始之前需要準備什麼

**你需要：**
- 任意一個聊天型 AI 帳號，例如：
  - **Claude**（claude.ai）— 免費版可用，Pro 版上下文更長
  - **ChatGPT**（chat.openai.com）— 免費版可用，GPT-4o 效果更好
  - **豆包**、**Kimi**、**DeepSeek** 等國內 AI 均可
- 大約 5-10 分鐘完成初次問卷

**你不需要：**
- 任何技術知識
- 心理學背景
- 提前準備材料（邊聊邊給也可以）

## 怎麼用

**第一步：取得提示詞檔案**

從檔案包裡打開 `psychai_prompt_v1_tradcn.md`，把「以下內容為系統提示詞正文，請從此處複製」下面的全部內容複製下來。或者直接把檔案上傳到 AI 對話裡，不用複製貼上。

**第二步：載入提示詞**

有三種方式，選一種：

- **方式 A（推薦，Claude）**：在 claude.ai 建立一個新 Project，進入 Project 設定，把提示詞貼進「System prompt」欄位，然後在這個 Project 裡開始對話。同一 Project 裡的對話都會自動載入，不需要每次重複。

- **方式 B（上傳檔案）**：直接把 `psychai_prompt_v1_tradcn.md` 上傳到對話裡，AI 會自動讀取檔案內容。Claude、ChatGPT 等均支援。

- **方式 C（通用）**：在任意 AI 平台開一個新對話，把提示詞正文作為第一條訊息發送，然後繼續聊。每次新對話需要重新發送。

**第三步：跟著它的引導走**

它會先自我介紹，然後引導你回答幾個問題。問題沒有對錯，寫多寫少都行，越具體它分析得越準。

你也可以跳過問卷，直接把日記、聊天記錄或者其他材料丟給它開始分析。

---

## 什麼材料最有用

它能處理各種文字材料，以下這些效果最好：

| 材料類型 | 說明 |
|---------|------|
| **日記／隨筆** | 任何你寫過的，關於自己、情緒、事件的文字 |
| **聊天記錄** | 和朋友、家人、伴侶的對話片段（複製貼上即可） |
| **錄音轉寫** | 對自己說話的錄音、和他人對話的錄音，轉成文字後貼進來 |
| **隨手寫的東西** | 不需要是正式的，碎片也行 |
| **直接對話** | 不提供材料、直接跟它聊，也能做分析 |

材料字數越多，通常分析越準確，因為能看到的行為模式更完整。

## 跨對話保存進度（快照功能）

大多數 AI 每次新開對話都不記得上次聊了什麼。PsychAI 用「快照」解決這個問題：

**生成快照**：完成第一次分析後，它會自動在輸出末尾附上一段 `【PsychAI檔案快照】`，格式是結構化的檔案摘要。

**使用快照**：下次開新對話時，把這段快照貼到對話最開頭，它會直接從你的當前檔案狀態繼續，不需要重新走一遍問卷流程。

**更新快照**：每次提供新材料、檔案有實質更新後，它會自動附上新的快照。用新的覆蓋舊的儲存就行。

建議：把最新的快照存在一個固定的地方（備忘錄、文件都行），每次用之前複製一下。

## 它不能做什麼

- **不是心理治療**：它的分析基於你提供的文字，不能替代面對面的專業評估
- **沒有醫療功能**：不能診斷任何心理疾病，不能開具任何建議或治療方案
- **不儲存你的資料**：所有內容只存在於你和 AI 的對話裡，關掉就沒了（這也是需要快照的原因）
- **分析有侷限**：它只能看到你願意說的部分，隱瞞的部分它不會知道

如果你的情況已經比較嚴重，影響到了正常生活，請尋求專業的心理健康幫助。

## 常見問題

**Q：用哪個 AI 比較好？**
哪個你用得順手就用哪個。Claude、ChatGPT 的上下文視窗較長，處理大量材料時更穩定；豆包、Kimi 等國內 AI 無需梯子，更容易上手。免費版通常足夠，有大量材料需要分析時付費版體驗更好。

**Q：我的隱私會被洩露嗎？**
你的對話內容由你所使用的 AI 平台處理，PsychAI 本身不收集任何資料。各平台的隱私政策不同，建議查閱你所用平台的官方說明。如果對隱私有顧慮，可以在提供材料時對人名等敏感資訊做模糊處理。

**Q：它分析的結論準嗎？**
它基於你提供的材料做推斷，材料越真實完整，分析越接近實際情況。如果它的結論跟你的判斷不符，可以直接告訴它，它會根據你的糾正更新分析。你對自己的了解永遠優先於它的推斷。

**Q：可以一次分析多個人嗎？**
可以，你可以提供關於其他人的材料（比如和某人的聊天記錄），讓它幫你分析對方，或者分析你們之間的關係動態。

**Q：它支援中文以外的語言嗎？**
支援。如果你用英文和它交流，它也能理解並回應。本說明書另有簡體中文版和英文版，見同一檔案包內。

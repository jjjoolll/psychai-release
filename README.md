# PsychAI

**作者：伪63 · 许可证：CC BY-NC-SA 4.0 · 商业授权：j0sphe8@outlook.com**

基于 11 大临床心理学框架的个人心理分析工具。提供文字材料，生成完整心理档案。

---

## 选哪个版本？

| | Option B（提示词版） | Option A（Skill版） |
|--|--|--|
| 使用方式 | 粘贴提示词到任意 AI | Claude Code 本地 Skill |
| 安装门槛 | 零安装，即开即用 | 约 30 分钟配置 |
| 核心优势 | 任何 AI 均可，免费版足够 | 自动读取本地文件，档案持久保存 |
| 适合谁 | 想快速体验 | 想要完整自动化体验 |

> **作者强推 Option A**：档案真正跟着你走，自动读取本地文件，分析越做越深。Option B 适合先感受一下，Option A 才是完整体验。
